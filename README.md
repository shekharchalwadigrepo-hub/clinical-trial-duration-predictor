# Clinical Trial Duration Predictor

End-to-end data science project that predicts the duration of clinical trials using publicly available data from ClinicalTrials.gov.

## Features
- Data extraction with `{ctrdata}`
- Feature engineering & cleaning
- Machine learning models (Elastic Net, Random Forest, XGBoost)
- Interactive Shiny dashboard
- Fully reproducible with `{renv}` + Quarto report

## How to Run Locally
1. Clone the repository
2. Open the `.Rproj` file in RStudio
3. Run `renv::restore()`
